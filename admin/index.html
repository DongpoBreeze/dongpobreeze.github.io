      登录 DongpoBreeze 账户，打开 GitHub fine-grained 令牌页面 ↗。Resource owner 选择 DongpoBreeze。

    2. 只授权这个博客仓库

      Repository access 选 Only select repositories，手动只选 dongpobreeze.github.io（链接不能自动选仓库）。Permissions → Repository permissions → Contents: Read and write。无需其他权限。
