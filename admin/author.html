验证作者身份

使用 GitHub 专用令牌，进入你的个人写作室。

  1. 创建专用令牌

    登录 DongpoBreeze 账户，打开 GitHub fine-grained 令牌页面 ↗。Resource owner 选择 DongpoBreeze。

  2. 只授权博客仓库

    Repository access 选 Only select repositories，手动只选 dongpobreeze.github.io。Permissions → Repository permissions → Contents: Read and write。无需其他权限，链接不能自动选择仓库。

  3. 生成后粘贴到下面

    点击 Generate token 后复制令牌。令牌只发送到 api.github.com，不会出现在链接中。

仅在当前浏览器会话保存。关闭会话后需重新验证；令牌不会写入草稿、仓库或导出文件，请勿在共用设备上保持登录。

验证只开放作者的创作管理权限，公众阅读始终无需登录。
